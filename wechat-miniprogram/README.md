## 当前本地版能力

- 使用微信小程序本地存储保存关系、记录和提醒设置；
- 不设置账号，不连接业务服务器，不上传用户记录；
- 支持文字、截图、小票和礼物四种记录入口，图片复制到本小程序的本机目录；
- 截图／小票记录优先使用微信 VisionKit 在设备端 OCR，识别金额、日期、时间和对象候选；结果只用于预填，必须由用户确认；
- 支持按关系、年份、月份、类目、是否达到提醒线及是否含截图筛选，并可按时间或金额排序；
- “说清”默认显示达到单笔提醒线的记录，也可切换查看未提醒或全部记录，并支持多笔选择、可编辑沟通稿、逐笔截图材料、咨询补充说明、本机材料预览和文字摘要复制；
- 内置普法小课堂默认内容及官方来源链接；
- 支持提醒线、关系管理、统计、数据文本留存（不支持导入恢复）、隐私说明和本地数据清除；
- 不支持 VisionKit 的微信版本或机型会自动回退为手动填写；暂不包含订阅消息、在线咨询、支付、云同步、真实 PDF、电子签或跨设备分享；
- 使用工具不当然建立律师委托关系。

## 本地保存说明

- 文字数据保存在微信为本小程序提供的本地存储中；
- 截图和照片保存在本小程序的本机用户文件目录中；
- “复制数据文本”不包含图片文件，重要图片仍应另行保存原件；
- 清理微信数据、删除小程序数据或更换设备，可能导致本地记录和图片丢失。

## 代码验证

使用Node.js在仓库根目录运行以下检查，无需业务服务器或第三方依赖：

```sh
node wechat-miniprogram/tests/run-unit.js
node wechat-miniprogram/tests/run-final-regressions.js
node wechat-miniprogram/tests/run-storage-navigation-regressions.js
node wechat-miniprogram/tests/check-structure.js
```

这些检查使用隔离的模拟微信接口，不读取或修改真实用户记录。模拟器页面检查脚本为 `tests/run-e2e.js`，需另行准备 `miniprogram-automator`，并通过 `WECHAT_AUTOMATOR_MODULE` 指定模块路径及启用开发工具自动化连接；本轮未将模拟器主流程计为通过。代码检查不能代替真实手机上的选图、权限、OCR、键盘和返回提示验收。
